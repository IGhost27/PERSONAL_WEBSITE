# Image guide

Replace the placeholder media by adding your own optimized WebP or AVIF files here.

- `backgrounds/hero.webp` - 2400 x 1600 recommended
- `backgrounds/og-image.jpg` - 1200 x 630
- `profile/portrait.webp` - 1600 x 2000
- `projects/[project-slug]/cover.webp` - 1800 x 1200
- `fitout/[adventure-slug].webp` - 1800 x 2200
- `travel/[location-slug].webp` - 1800 x 1200

Update matching `image` fields in `src/data/` after adding files.
